# 映序详细功能地图

更新：2026-11-10

## 使用说明与证据边界

- 本表描述**当前源码中的真实页面**，用于后续产品、设计和开发迭代。原型、PRD、未挂载的旧账号分析组件不算当前页面。
- 入口统一为客户端内的 `/demo/*`；表内省略 `/demo`。已在隔离工作区通过真实 Chrome 检查 22 个主要路由的渲染、标题和控件；新“接入向导”证据为 `docs/acceptance/browser-dedicated-setup.png`。
- “入口已验证”只表示页面可以打开，**不表示 AI 生成、平台同步、上传或公开发布已经再次验收**。真实账号、外部模型和平台结果仍以各自现场验收为准。
- 空状态、条件按钮和弹窗依据当前 TSX 源码补齐。没有真实数据时不会伪造卡片、项目或发布结果。
- `/accounts/*` 当前重定向首页，不是独立新版账号分析页。旧版 `/legacy` 单列，不能与新版功能混写。
- **控件级说明书见文末 A～K**：从当前 TSX 提取并复核 534 个按钮、输入框、选择器及链接节点；同类动态控件合并说明，逐项列出点击效果、输入内容、必填规则、长度／数值范围、文件类型和禁用条件。
- **页面—卡片—功能—技术矩阵见 `docs/FUNCTION_MATRIX.md`**：按一级页面、二级卡片、三级元素、功能描述、技术方案五列组织，用于查看模块边界和真实调用关系。
- **逐页离线评审入口见 `docs/iteration-review/index.html`**：按照确认的单页样板完整 review 每个页面，并保留每次迭代记录；资料夹使用与更新规则见 `docs/iteration-review/README.md`。

## 3. 文章任务

| 设计 | 功能详情 | 备注 |
|---|---|---|
| 文章列表 `/articles`：全部文章卡 | 搜索、状态筛选、分页；“新建文章”；选择文章进入独立路由 | 已验证入口；按最近更新排序 |
| 新建文章弹窗 | 输入文章主题、初始写作要求；“创建本地文章”“取消”；空状态也可“自由写作／粘贴已有稿” | 只创建本地任务，不自动生成或发布 |
| 文章编辑器 `/articles/:id`：顶部与切换弹窗 | 返回列表、切换文章、查看状态、版本与文章信息；编辑自动保存为本机草稿 | 正式版本与本机草稿不同；保存失败离开会提醒 |
| 工作区标签 | “写文案／配图片／排版交付”切换同一文章的三个工作区 | 不是三个独立文章 |
| 写文案：文章要求卡 | 填写补充要求，作为本次生成输入 | 不覆盖其他 Agent，不自动成为正文 |
| 写文案：论证大纲卡 | “文案 Agent 生成大纲”；编辑大纲；“确认大纲，用于生成正文”保存正式版本 | 生成依赖模型；保存新版本会使下游旧审批失效 |
| 写文案：完整正文卡 | “文案 Agent 生成正文”；“保存正式版本”；“提交人工审核”；“我已核查并批准当前正文”“退回修改” | 人工审批绑定具体正文版本 |
| 写文案：创作计划与配图位置 | 平台、写作目的、图片位置和方式；“加入写作要求”“保存正式版本”“添加配图位置／移除位置” | 规划不代表图片已生成或已授权 |
| 配图片：搜索与生成 | 填写图片需求；“搜索图片”；结果“下载并采用”；“生成图片” | 搜索、下载、AI 生成是不同能力；失败不伪装为已采用 |
| 配图片：本地素材与排序 | 选择本地图片、调整配图位置、查看素材和 credits | 修改图片后需要重新确认对应交付版本 |
| 排版交付 | 平台排版、分页长图、HTML／Markdown／ZIP 等真实导出；“导出当前正文”；下载已产生的文件 | 未导出时显示空状态，不提供虚假下载 |
| 排版交付：继续制作与发布 | “从已保存正文制作视频”；“前往发布中心” | 未保存修改或正文未批准时不能当作已交付 |

## 4. 视频项目首页与原创流程

| 设计 | 功能详情 | 备注 |
|---|---|---|
| 视频项目 `/projects`：页头 | “新建原创”“新建对标”分别进入两条流程 | 已验证入口；侧栏也可展开两个子菜单 |
| 视频项目：工具卡 | 按名称或编号搜索；按全部／原创／对标筛选；“新建视频”进入原创 | 不写死示例项目 |
| 视频项目：项目卡 | 显示类型、标题、项目 ID、更新时间和交付状态；点击继续原项目 | 旧项目 ID、素材和版本沿用原任务数据 |
| 原创 `/projects/original[/:id]`：01 文案创作 | 可手写完整文案，也可按叙事方向生成／改写候选；“采用为正式文案／保留当前文案”；确认后进入视频生成 | 手写不强制叙事方向；AI 生成必须填写方向；候选采用后才替换正式文案 |
| 原创：02 旁白与时长 | 上传真人旁白，查看时长与转写；“生成词级时间码（必需）”“确认旁白与时长”“上一步” | “AI 修改旁白”按钮明确未接入；没有有效时间码不能继续 |
| 原创／对标：03 音乐卡 | 选择已有配乐、导入音乐；“AI 生成配乐（Kimi）”“AI 适配时长”“试听适配后配乐与旁白”“分离当前音频人声／伴奏” | Kimi 负责创作／规划，本地引擎合成和分离；文件独立保存 |
| 原创／对标：音乐确认 | “确认适配效果”或“确认不另加音乐”；“确认音乐／确认音乐，继续合成” | 必须处理音乐冲突和确认状态，未确认不能继续 |
| 原创：04 生产画面与画风 | 选择真实画风；“生成分镜”“分别生成已选分镜（Kimi + Remotion）”；逐镜编辑；返回上一步；满足条件后进入合成 | 模板弹窗提供“使用这个画风”“按新风格提出修改建议”；未配置的风格库按钮保持禁用 |
| 原创：镜头详情弹窗 | 修改起止时间、画面说明和素材；“AI 生成新版本”“保存本镜”“确认本镜” | 上传与 AI 版本分开；“试听对应旁白（未接入分段播放）”明确未接入 |
| 原创／对标：样片区 | “生成样片”；逐条预览并点击“样片通过”；全部必需样片确认后生成完整成片 | “打开 Remotion 时间线（未配置）”不是可用功能 |
| 原创／对标：05 合成与验收 | 检查时间线说明；“生成完整成片”；选择成片版本并预览；“返回修改”“验收通过” | 上传的单镜素材不能冒充最终成片 |
| 原创／对标：交付 | “下载成片”；“推送到发布中心”建立审核关联 | 推送后进入审核，不等于公开发布 |

## 5. 对标流程

| 设计 | 功能详情 | 备注 |
|---|---|---|
| 对标 `/projects/benchmark[/:id]`：01 提供参考 | 上传真实参考视频，可选填写关注重点；“查看拆解报告” | 首屏直接提供参考，没有重复创建层，不要求使用边界 |
| 对标：02 拆解报告 | 查看整片转写或画面字幕、逐镜时间码、画面说明和原视频；“用 Kimi 分析关键帧”“导出报告”“基于分镜继续制作”“返回提供参考” | 报告来自真实上传和拆解；无音轨时用 RapidOCR 读取画面文字，不冒充口播 |
| 对标：03 逐镜替换卡 | 原镜头与新版本并列；逐镜编辑；选择多镜生成；全部确认后继续音乐 | 保留原始时间码，不用模拟镜头替代 |
| 对标：镜头详情弹窗 | 原视频时间码、原旁白、原画面只读对照；“保留原镜头”；上传替换视频、调整旁白／音轨／时长；“AI 生成新版本”“保存本镜”“确认本镜” | 保留、替换和 AI 版本分开；静音、循环、末帧等按真实制作参数执行 |
| 对标：04 替换音乐 | 与原创共用音乐选择、生成、适配、试听、分离和冲突确认 | 不覆盖原曲或用户素材 |
| 对标：05 合成验收 | 与原创共用样片、完整成片、人工验收、下载和审核交付 | 真实关联同一项目 ID 和制作版本 |

## 6. 旧视频编辑器与兼容页

| 设计 | 功能详情 | 备注 |
|---|---|---|
| 兼容入口 `/tasks`、`/tasks/:id` | `/tasks` 显示项目首页；旧项目详情按原创流程打开 | 原深链继续有效，不要求迁移旧数据 |
| 原编辑器 `/tasks/:id/editor`：项目与阶段卡 | 返回最新任务、刷新数据、查看任务历史；按文稿、录音字幕、素材、制作、结果质检、复盘继续 | 原六阶段能力保留，不是另建第二套应用 |
| 文稿阶段 | 母稿／平台稿编辑；“生成此栏／根据现有资料重写”“保存手填文稿”“保存并确认口播稿” | AI 与人工版本均留痕 |
| 录音与字幕 | 上传真人录音；系统语音／本人克隆生成；WhisperX 生成 SRT；手动上传 SRT；试听、下载、校对；“确认录音与字幕”“返回修改脚本” | 录音和有效 SRT 必须同时存在 |
| 素材清单 | AI 生成分镜建议；上传素材及授权凭证；添加／移除分镜，填写来源、时间、类型和授权；“保存”“跳过未完成项”“确认全部素材与授权” | AI 建议不表示素材已授权 |
| 制作与生产 | 选择智能混合／素材混合／全部上传、目标平台、模板；生成、取消或重试生产；手动上传成片；AI 封面、抽帧封面、上传封面 | 重复上传成片会使旧质检失效 |
| 结果与五项质检 | 选择版本、下载、质检／审批、重新生成；五项人工检查、备注、返修素材／仅重做成片、提交人工审核 | 每个风格版本独立质检和审批 |
| 人工终审与复盘 | 完整观看后“批准此版本”；录入四窗口真实指标；“保存复盘数据”“保存并完成复盘归档” | 质检、人工终审、发布确认是三个不同检查点 |

## 7. 审核中心

| 设计 | 功能详情 | 备注 |
|---|---|---|
| 审核 `/review`：映序成片卡 | 显示来源项目、文件 ID、制作版本；“返回映序制作”；内容变化时提示关联失效 | 有交付关联时才显示；不重新上传原文件 |
| 来源卡：选择或切换内容 | 输入／选择本地文件夹；“读取文件夹”“新建上传批次”；上传多个 MP4／MOV／WebM／MKV | 只扫描当前目录，不递归，不修改原文件 |
| 机器预审卡 | 设置宽高、最长时长、黑帧和静音阈值；可选 OCR 字幕越界、AI 风险证据；“开始机器预审” | OCR／AI 是辅助证据，不等于完整合规结论 |
| 批次进度卡 | 总数、待终审、通过、驳回／失败统计；“通过全部无阻断项” | 只处理符合人工通过条件的项目 |
| 单视频审核卡 | 播放视频、查看技术检查、问题时间点、AI 风险和原始 JSON；“查看检查详情／收起证据” | 过期交付和预审中的项目不能直接批准 |
| 单视频操作 | “安全转码并复审”“驳回”“人工通过”；通过后显示实际输出文件 | 安全转码产生新输出，不覆盖原视频 |

## 8. 发布中心

| 设计 | 功能详情 | 备注 |

## 后续迭代维护规则

1. 新增或删除路由时，先改 `webapp/src/App.tsx`，再更新本表对应页面和 `PROJECT_MAP.md` 的路由表。
2. 新增卡片、按钮、弹窗或条件状态时，在同一行补充准确文案、真实接口和前置条件；每个输入框还要写明输入内容、是否必填、长度／数值范围、格式、文件类型和禁用条件；禁用或未接入能力必须写进备注。
3. 修改共享组件时，检查所有引用页面。例如发布平台卡会影响文章和视频，音乐会同时影响原创和对标，专用 Chrome 会影响选题、四平台登录和发布预填。
4. 每次迭代分别记录“入口验证、自动化测试、真实生成、真实账号、公开发布”证据，不能用前一层结果代替后一层。
5. 页面结构变化后，在隔离工作区重新走本表路由，更新对应截图和 `CHANGELOG_AI.md`；不要通过正式工作区制造演示数据。

| “最多尝试次数”数字框 | 设置含首次在内的尝试次数 | 整数 1～5 |
| “并发上限”数字框 | 设置该 Agent 并发数 | 整数 1～2 |
| “写作 Skills”文本域 | 每行填写一个只读 Markdown 路径 | 仅脚本／文章 Agent；只允许 `skills/` 或 `.agents/skills/` 下 `.md`；扩展配置序列化最多 4000 字符 |
| “保存该 Agent” | 校验并保存当前 Agent 独立配置 | 只影响之后新任务，不改历史产物或运行中任务 |
| “恢复该 Agent 默认” | 将当前 Agent 恢复默认配置 | 不影响其他 Agent；需要保存结果成功才生效 |
| 模板预览图 | 新标签放大真实模板预览 | 不是演示视频生成结果 |
| “升级为稳定” | 将模板状态改为 stable，允许正式制作使用 | 模板本身和版本保留 |
| “停用” | 将模板状态改为 deprecated | 不删除模板；新制作不能当作稳定模板使用 |
| “恢复为草稿” | 将模板状态改为 draft | 不等于稳定可用 |
| “默认服务”下拉框 | 选 Codex CLI、Kimi CLI 或 OpenAI 兼容模型 API | 只配置文本模型；本地 Whisper/OCR 等不在此选择 |
| “API 基础地址” | 输入 OpenAI 兼容服务地址，例如 `https://服务地址/v1` | 仅模型 API 显示；保存与测试需要有效服务地址 |
| “模型名称” | 输入 API 服务商的实际模型名 | 仅模型 API 显示；不能为空；未声明统一前端长度上限 |
| “API Key”密码框 | 输入服务商密钥 | 仅模型 API 显示；已保存时留空表示保留；保存后清空输入，不在页面回显 |
| “保存默认模型” | 保存系统默认服务及 API 配置，不执行连接测试 | 跟随系统的 Agent 下次执行使用；独立覆盖的 Agent 不变 |
| “保存并测试连接” | 先保存，再发起真实最小模型调用 | 保存成功但调用失败时显示错误，不写成已连接 |
| “刷新模型状态” | 重新读取文章插画与本地渲染状态 | 不生成图片 |
| “字幕环境 Python”等路径输入框 | 分别填写 Whisper、RapidOCR、Demucs、OpenVoice 的 Python 路径 | 路径须指向真实可执行环境；保存不等于测试通过 |
| “OpenVoice 模型文件夹” | 选择 OpenVoice 模型根目录 | 使用文件夹选择器；其他 Python 路径使用文件选择器 |
| “保存环境位置” | 保存上述本地工具路径 | 必须再运行真实测试，不能显示路径就变已连接 |
| 本地媒体“真实测试”按钮 | 分别运行 Remotion、系统语音、WhisperX、OpenVoice 临时自测 | 使用临时文件，不加入内容任务、不自动启用 Agent |
| “素材路径／原素材的新位置”输入框 | 输入要导入的视频、音频、图片、字幕，或失效素材的新位置 | 必须非空且文件真实存在；重新定位需验证内容相同 |
| “复制进本地素材库”复选框 | 导入时选择复制文件，而非默认引用原文件 | 仅新导入显示；默认不复制、不重复占磁盘 |
| “导入素材” | 校验文件并保存引用或本地副本 | 路径为空时禁用；不上传云端 |
| “重新定位” | 进入某个失效引用素材的路径修复状态 | 不立即修改，需再验证 |
| “验证并重新定位” | 验证新文件后更新该素材位置 | 内容不相同或不可用会拒绝，不静默换成别的素材 |
| “取消” | 退出重新定位状态并清空路径 | 不改变原记录 |
| “素材类型”下拉框 | 筛选媒体／字幕或全部文档与导出包 | 每次切换恢复显示前 10 个 |
| “显示更多素材” | 每次多显示 10 个 | 只展开列表 |
| “缓存容量”数字框 | 设置可重建渲染缓存容量 | 整数 1～1000；非整数或越界禁用保存 |
| “保存容量” | 保存缓存容量设置 | 不清项目、素材或成片 |
| “清理可重建缓存” | 删除系统判定可重建的缓存内容 | 没有可清理字节时禁用；业务文件不在范围内 |
| “刷新占用” | 重新读取缓存占用 | 只读刷新 |
| “新的导出／恢复目录” | 输入迁移包或恢复目标的新目录 | 必须不存在；导出目录不能在工作区内；恢复不得覆盖现有系统 |
| “导出完整工作区” | 校验并打包文章、项目、版本、素材及外部引用文件 | 目标为空或已存在会拒绝；缺失素材会阻止完整导出 |
| “迁移包目录” | 输入之前导出的完整迁移包位置 | 必须真实存在且指纹校验通过 |
| “校验并恢复到新目录” | 验证迁移包后写入全新目录 | 源包和目标目录均必填；磁盘空间不足或目标已存在会停止 |

| “校验并切换工作区” | 校验后切换工作区并重启服务 | 有任务运行时不可切换；原数据保留；切换前会刷新本机草稿 |
| 数据与隐私说明区 | 查看存储、模型输入、人工审核和发布边界 | 无删除、清空或导出隐私数据按钮 |
