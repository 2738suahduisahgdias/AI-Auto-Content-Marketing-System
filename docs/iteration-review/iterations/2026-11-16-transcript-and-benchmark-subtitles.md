## 实际变更

1. 原创转写从 `beam_size=1` 调整为 `beam_size=5`，worker 接收 200 字符以内的开头语境与全文英文品牌术语，同时作为 initial prompt 与 hotwords，避免长提示触发模型位置编码上限。
2. `transcript_prompt` 只保留短文语境和品牌术语，不把定稿文案直接当作识别结果；仍需人工校对。
3. 新建和重新拆解对标不再要求“使用边界”；旧数据中的该字段不删除，但页面不再展示或拦截。
4. 无音轨时不再只显示“旁白未识别”，而是对真实关键帧调用现有 RapidOCR，分别保存 `subtitle_text`、`subtitle_confidence`、`subtitle_status` 和 `subtitle_error`。
5. 报告分别显示“旁白”和“画面字幕”，明确 OCR 不等同于口播；OCR 失败保留拆解结果并显示原因。
