# 2026-11-24：预览平台登录与共享浏览器恢复

## 范围

- 修复 8847/8876 接入向导、抖音和小红书登录任务，以及四个平台共用专用 Chrome 的生命周期。
- 不修改正式 8848、数据库结构、账号凭据或发布状态。

## 实际变更

1. 预览后端强制启用 `YINGXU_DEDICATED_CHROME=1`，避免登录检查退回临时浏览器并在结束时关窗。
2. 预览 worker 复用现有执行器，注册并允许 `accounts.login`、`topics.login`、`topics.xhs_login`。
3. 新增共享环境、登录 worker 注册和允许调度的回归测试。
4. 更新 `docs/modules/integrations.md`，区分浏览器可用、任务执行、本人登录和上传验收。

## 真实验证

- 原 `topics.login` 已从 `queued` 变为 `running`，后续账号登录按浏览器资源锁排队。
- 接入页实际启动专用 Chrome；Playwright 断开后 `127.0.0.1:9223` 仍监听。
- 小红书、抖音、视频号和公众号均实际打开并执行登录判断；未通过判断的页面也未关窗，最后仍是同一 Chrome PID 76123。
- 相关 62 项 unittest 通过。
