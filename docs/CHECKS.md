## 6. 数据保护

- 只读 SQLite：`sqlite3 -readonly ...`，不直接执行迁移、UPDATE、DELETE 或 INSERT。
- 只读媒体：`ffprobe`、文件存在性和 SHA-256；不覆盖、转码、重命名或移动原文件。
- 不在真实工作区测试新建项目、恢复、切换、清理缓存、模型生成或平台同步。
- 页面可能自动保存草稿，检查时不主动编辑；需要绝对无写入时优先数据库和文件检查。
- 不记录或复制授权码、Cookie、Token、私钥、账号密码和私人正文。
