# 文案与图文创作改造规格

本次为原 Articles 页面上的设计增量。沿用原文章 ID、选题来源、版本保存、大纲正文生成、人工审批、导出与发布交接，不新建文章系统。平台选择、配图策略和格式目前是未持久化的需求编排预览；可以加入当前生成提示，不能当作图片或排版任务已执行。

## 用户流程

1. 从原选题中心选择文章选题，沿用原来源与关联 ID；或新建文章自由输入想法、粘贴自己的稿件。
2. 文案 Agent 根据主题、用户资料、品牌记忆撰写；人工可直接改稿保存。AI 大纲与正文生成沿用现有实现，不强行要求手写稿先生成大纲。
3. 配图支持网络搜索、AI 生成、本地图片或不配图。先生成段落级配图计划，由用户挑选、替换和确认，不能把候选图当已采用素材。
4. 公众号交付标题、摘要、封面及带图正文 HTML；小红书交付标题、正文、话题及按阅读顺序分页的图片。支持平台文本、长文图片或两者。平台版本独立，不能覆盖母稿。
5. 图文质检后人工审批，交给发布 Agent 预填；本页不直接公开发布。

## Agent 技能接线

以下为职责及拟接线，不代表已安装或执行对应 skill。

| 职责 | 候选技能 / 实现 | 接口约定与验收 |
|---|---|---|
| 主题与记忆读取 | 原选题 API + 本地记忆检索适配器 | 传 topic_id、来源及版本、证据引用；自由写作允许 topic_id 为空 |
| 原稿写作与改写 | 现有 article.outline / article.draft | 保留 expected_version、输入快照、错误状态；不覆盖用户尚未保存文字 |
| 小红书适配 | 可评估 xhs-post、zhongcao，先审查能力与冲突，再选一个主流程 | 输出标题、正文、话题、配图计划；平台规则标记版本，不能写死旧规则 |
| 公众号适配 | 待接公众号编辑 skill + 本地排版模板 | 输出标题、摘要、分节正文、封面及文内插图锚点 |
| 图片搜索 | 待接图片搜索 API / 本地图库技能 | 候选含 source_url、作者/使用信息、尺寸；搜索不等于已获使用权 |
| AI 配图 | 待接图像模型适配器，可参考 imagegen 职责 | 图像 API Key/本地模型独立配置；输入提示词与品牌风格，输出本地资产 ID、模型和版本 |
| 排版与长图 | 待实现本地 HTML/CSS 模板 + 浏览器渲染适配器 | 公众号 HTML 样式适配；长图分页、字体检查、超长内容边界、导出顺序与本地输出路径 |
| 质检与交接 | 原审核和发布 Agent 扩展图文资料包 | 文本修订、图片清单、排版模板版本绑定；改稿/换图使旧审批失效；人工确认发布 |

## 数据与依赖

在原文章上扩展平台版本与配图资产清单，禁止新建平行项目数据库。图片保存在本机或外接盘，默认引用用户原图。API Key 不进入稿件、普通日志和项目导出。联网找图和生图分别标注网络依赖、费用和发送范围；仅本地排版不发送整篇稿件到外部。

当前 Markdown / 安全 HTML 导出不代表已经完成公众号专用排版或长图生成。后续需补充版本绑定、真实图像生成/搜索、模板预览、长图输出、图文审核和发布适配的端到端测试。

## 最新确认的交互调整

页面分为写文案、配图片、排版交付三个工作区。选题、自由想法、已有稿件是平等入口；已有文案不强制生成大纲。主要平台与写作目的放在编辑之前，配图及交付形式稍后决定。每个图片位置可独立选搜索、生成或本地引用，支持混用及纯文本。公众号优先可编辑正文，小红书可用文字笔记或分页图文。技能备注放入设置的 Agent 配置；用户创作页只显示对应依赖。

当前设计预览的图片计划和平台选择仅在页面内存中，刷新重置；未接素材 API、持久化或实际排版导出。正文仍沿用原版本接口。后续接入需补母稿到平台版本的另存、图文共同审核及修改失效测试。

## Codex CLI 接入验收

本机 Codex CLI 0.166.0-alpha.5.1 显示已使用 ChatGPT 登录。经用户明确批准，将不含客户资料的“AI 客服如何落地”通用提示送入 CLI，真实返回三点大纲且小于 120 字；使用 JSON text 协议成功解析。此证据只覆盖该次文本调用，不能推断未来登录永不过期或额度无限。

原 article_agent 新增 codex_cli 可选引擎，Kimi 保留。执行器读取程序目录的指令文件，在临时工作目录使用 read-only、ephemeral、ignore-user-config 模式，通过最终结果文件获取输出；不把客户项目目录作为 CLI 工作目录。仍需客户主动选择引擎及发起生成。未把 Codex 接到视频大模型、图片生成或平台发布；这些是不同能力。

### 本地配图与可迁移图文交付

- 配图位置保存 `asset_id` 与 `after_paragraph`；0 表示正文之前，正文按空行分段。保存正文时验证资产存在、文件指纹、格式与段落范围，并建立原有版本依赖。换图/改位置使用原有审批失效逻辑。
- 导出继续使用已批准正文。HTML 自包含图片；Markdown 使用相对图片路径；新增 ZIP 包内含 HTML、Markdown 与原图。单图上限 20 MB，总配图 50 MB。视频素材不受此图片限制影响。
- 导出期间文件被修改或正文被其他窗口改动，不能激活旧导出。图片格式检查与 HTML 转义防止直接插入 SVG/HTML；Markdown 正文本身保留用户原稿。
- 发布来源携带图片资产及指纹。当前平台适配器尚未实现正文配图上传，含图自动预填/执行明确返回 `ARTICLE_IMAGES_PREFILL_PENDING`，不会把纯文字预填当作图文成功。现阶段可使用图文包手动导入；未伪装成完整平台自动发布。
- 尚未实现：网络搜图、生图模型、长图分页、平台原生图文自动预填。上述事项不因本地导出完成而标为已上线。
