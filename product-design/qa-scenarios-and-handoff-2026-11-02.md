## 技术负责人待修问题

### QA-01 / P1 / 实际复现：旧页面会话失效无法自行恢复

复现：保留设置页→服务重启（本会话已有）→点击“刷新真实状态”。实际提示“本地会话已失效”，仍显示旧 Remotion 404 和字幕/克隆未就绪；整页刷新后四项显示已连接，与 `/api/bootstrap` 一致。

修改入口：`webapp/src/lib/api.ts`、`webapp/src/pages/Settings.tsx`、本地会话 bootstrap。检查旧接口 SESSION 错误与新接口的恢复条件差异。只对明确执行前拒绝恢复；不能重试已经执行的发布/上传。

验收：旧标签跨服务重启后点击刷新自动恢复；保留未保存配置；过期会话的读请求与写请求各有回归；不得仅靠要求用户 F5。

### QA-02 / P1 / 已确认交付缺陷：模型环境依赖开发机旧目录

当前 `.venv-faster-whisper`、`vendor/OpenVoice`、`vendor/openvoice-venv` 使用本机旧系统目录的依赖链接；本机真实测试通过不能证明客户机器存在这些目录。

修改入口：`desktop/build.py`、`desktop/entry.py`、模型安装/检测与媒体引导。应打包或安装到客户可配置本地依赖目录，展示下载大小、进度、失败原因、重试入口及探测结果。

验收：无旧工程目录的干净 Mac 跟随引导完成字幕与音色测试；离线缺模型时明确不可用和替代方案。

### QA-03 / P1 / 已确认交付缺陷：安装包未包含最新修复

本地服务已修复音频资源与字幕检测、文件选择，但已安装包未完整重新生成；启动源码服务与安装包结果不能混用。

修改入口：构建流水线、版本信息与包内自检。验收：从最终 DMG 安装后，不依赖源码，重跑 S01/S03/S12/S16/S17；明确签名公证状态。

### QA-04 / P1 / 已确认未实现能力：AI 视频大模型

运行能力接口返回 `not_implemented`；目前不能宣称广告片/小短剧的 AI 视频生成已可用。Codex CLI 配置不能直接视为视频生成接口。

修改入口：视频制作场景/生成按钮、能力检测、提供者适配。验收：未接通时入口明确不可用，并提供上传视频/Remotion 路径；接通后真实片段验收才标成功。

### QA-05 / P1 / 验收缺口：平台登录不等于可预填上传

公众号、视频号自动上传未完成真实验收；抖音、小红书本轮也没有真实重传。不能由 bridge=true 推导平台登录和发布链路可用。

修改入口：发布中心及 setup 状态探测。验收：四平台逐一记录登录、标题/正文、图片/视频上传结果；失败转入手动复制和素材下载；人工最终发布。

### QA-06 / P2 / 已确认缺口：磁盘迁移之后不能直接选择新工作区

现有页面提供导出恢复，缺少明确的当前工作区切换入口。导出成功不等于启动位置已改变。

修改入口：`WorkspaceTransfer.tsx`、桌面 workspace pointer 与启动服务协调。验收：展示当前路径→选择/迁移→校验→安全切换→重启仍使用新磁盘；失败保留原库；有活动任务时禁止切换。

### QA-07 / P2 / 代码审查发现：缓存复制范围与管理统计不一致

`render.mjs` 为渲染同步整个 `public/assets` 到每个 bundle 缓存，当前页面管理的是 `public-static/yingxu-assets`；大视频和多个 bundle 版本可能重复复制且未计入这张卡片。当前 bundle cache 约 43MB，未进行大规模压力复现。

修改入口：渲染素材发布、`RenderCache` 统计/清理。验收：只处理当前渲染依赖；统计包含构建缓存；大文件重复渲染不持续增加重复副本；清理不得删除原素材或运行中任务文件。

### QA-08 / P2 / 代码审查待核实：当前 CLI 模型配置可能不被继承

Codex provider 调用包含 `--ignore-user-config`，且未显式传递 Agent 模型；与“使用当前 Codex CLI 配置”存在语义差异。不能仅看下拉框已保存判断实际模型。

修改入口：`providers/text.py`、Agent 模型配置与审计记录。验收：安全保留隔离执行要求，明确默认/指定模型规则，并记录真实执行模型；不读取或展示用户密钥。

### QA-09 / P2 / 实际观察：素材列表混入导出文件且缺少类型筛选

本地素材当前列出了 ZIP、HTML、Markdown 和图片，名称部分为内容哈希；对只想选择视频/图片的用户难以识别。

修改入口：`LocalAssets.tsx`、素材元数据。验收：按媒体/文档/导出包筛选；优先展示原名称；保留原有资产和引用，不删除研究/导出文件。
