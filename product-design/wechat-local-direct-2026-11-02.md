# 新系统微信直连（2026-11-02）

## 已实现

- `content_workbench/topics/wechat_client.py`：独立扫码连接、平台消息接收、保存后回执；不运行旧 Gateway、Agent、CLI 或桥接脚本。
- 沿用 `WechatInboxService` 和原选题数据模型，消息按机器人 ID + 平台消息 ID 去重。仅接收扫码本人私聊。
- 凭据及游标在工作区 `config/wechat-client.json`，权限 0600；登录 API 不返回 token。
- 批次所有消息处理成功后才推进游标；失败重试，不虚报保存。
- 桌面服务启动自动恢复连接，退出停止接收。前端“选题 → 微信”提供获取扫码链接、检查连接和配对码入口。
- 旧 OpenClaw 配置已备份，旧 weixin 和 yingxu inbox 插件已设为 disabled。

## 验证

15 项 Python 测试通过（新连接 7 项 + 原收件箱 8 项），前端 TypeScript 和 Vite 构建通过。新系统实际成功取得微信官方二维码链接。真实扫码、真实消息入库和回执尚待用户配合，不能标记已验收。

## 当前边界

文本、链接自动入库；附件仅保存平台消息信息，不声称已下载。当前尚无完整的断开账号/更换账号 UI；客户端停止后不收消息。旧凭据没有复制到新连接，需用户扫码。现有安装包尚未重打包。

浏览器工具禁止访问微信官方扫码页面；由用户手动打开官方链接扫码，工作台通过自身登录状态接口核对，不能尝试绕过浏览器限制。
