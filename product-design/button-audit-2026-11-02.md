# 全站按钮与新手引导检查

## 根因与修复

1. 新手引导仅用 sessionStorage 记住本次展示，且拦截直接打开的视频任务。新增本地授权状态中的 presented，展示后持久保存；自动引导仅在首页首次进入时触发，不打断已有任务。授权及引导入口统一放在设置中。当前用户已通过正常结束引导操作保存 completed。
2. Chrome 实测点击视频“规格与节奏”无反应，控制台明确报告 CSP 拒绝 eval。201 处 HTML 内联事件改为直接闭包函数绑定，没有放宽 CSP。重新实测步骤切换、配乐弹窗打开和关闭有效。
3. 公共 Button 默认 type=button，防止表单内普通操作误提交；明确 type=submit 的提交按钮继续保留。
4. “无原链接”“Markdown 不可用”“HTML 不可用”改为说明，不再伪装成按钮。
5. Remotion 分镜保留真实单镜渲染，删除重复的“规划制作任务”。未接入的视频模型操作改为配置入口，不将模拟结果标成生成成功。云端配音模拟入口改为配置入口。
6. 项目导出使用当前项目名，移除旧示例名称。运行依赖说明与真实本地系统保持一致。

## 保留的点击逻辑

| 页面 | 必需操作 | 前置条件与结果 |
| --- | --- | --- |
| 今日工作 | 打开任务、创建任务、查看进度 | 跳转原任务或创建真实本地任务 |
| 选题中心 | 采集、推荐、收藏分类、下载、创建内容 | 后台任务提交；需平台登录时保留明确提示，不假装完成 |
| 微信收件箱 | 扫码、检查连接、手动记录、整理、归档、转任务 | 新系统直连；整理保留原始消息 |
| 视频任务 | 六步骤切换、保存稿件、素材引用/上传、分镜编辑、样片与成片渲染 | 写回当前原任务；真实素材和渲染依赖仍需满足 |
| 视频交付 | 选择成片、提交审核、跳转发布工作区 | 必须真实成片；不在编辑器直接公开发布 |
| 文章任务 | 新建、保存、大纲/正文、配图、审核、导出 | 正文生成需大纲；导出需批准；保留必要状态约束 |
| 审核中心 | 检查、批准、退回 | 关联实际交付版本；不绕过审核 |
| 发布中心 | 接收交付、生成字段、打开平台、准备草稿 | 保留人工终审；公众号/视频号真实自动上传仍未验收 |
| 账号日报 | 同步、生成推荐 | 需要真实账号数据；登录由用户完成 |
| 记忆大脑 | 查询、筛选、同步记忆、查看来源 | 使用现有知识存储与回填接口 |
| 设置 | Agent、模型、本地素材、模板、自动化、授权、引导 | 保留有效配置功能，不因某项尚未配置就删除整个能力 |

## 审查范围

`button-action-inventory.json` 按文件、行号保存全部 React button/Button 和映序 eventAttr 的事件绑定、禁用条件。可用 `node scripts/audit/buttons.cjs` 重建。静态绑定检查不等于每个外部 API 已验收。需真实发布、删除用户数据或消耗外部服务额度的按钮未通过批量乱点击测试。

前端全套回归及 Chrome 实测结果在最终验收后追加。权限、缺少必填输入、运行中任务等必要禁用状态仍保留，不盲目启用。
