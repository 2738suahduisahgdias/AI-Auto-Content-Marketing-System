# 全工作台 UI 一致性复查 · 2026-11-01

基于现有刘量工作台与映序迁移代码修改；不新建平行后台，不改变业务流程。采用暖白底、琥珀橙主色、少量香槟金辅助色。

## 发现与修复

1. 原来只用顶层主题覆盖，懒加载页面仍写死绿色背景、边框及衬线字体。已在各页 CSS 源定义中替换旧调色，并把共享设计变量集中到 `styles.css`。
2. 选题、文章、知识库、审核、发布、账号、设置与接入向导的选择状态、卡片、表单、表格和说明区域采用同一套变量。
3. 映序残留的紫色场景选中态、音量控件、音乐波形和步骤提示改为共享变量；素材图片、视频内容、平台品牌标识和模板概念示例配色保留。
4. Radix 弹窗渲染在 app-shell 外，原先未继承部分样式。已统一弹窗外观、焦点状态和文本框双向调整能力。
5. 发现采集知识库的抖音热榜和收藏夹记录共用 `douyin:research`，导致重复 React key 和详情错选。前端使用原 ID、URL、标题组成显示标识；不改接口或原记录。
6. 独立经营者授权后台也对齐背景、主按钮、输入框、卡片圆角和键盘焦点。
