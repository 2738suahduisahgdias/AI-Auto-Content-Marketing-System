引导：确认真实本地工作目录、真实依赖检测、按需配置能力、示例稿进入映序、中断继续、完成后不再自动弹出、手动重看。完成的是入门提示，不会虚报成片或发布成功。文案示例不要求文本模型；没有使用视频模型时不要求视频 API；平台账号仍按需在原向导设置。

## 本地文件与启动

运行数据均放在外接硬盘 `EXTERNAL_USB` 的 `映序开发/2026-11-01/runtime`：

- `migration-preview/license/state.json`：客户安装标识、授权、引导进度。
- `migration-preview/license/public-keys.json`：客户信任的公钥，不含私钥。
- `license-operator/customers.sqlite3`：正式客户发码记录。
- `license-operator/signing-key.encrypted.pem`：正式私钥（本人首次设置后才生成）。
- `license-acceptance-issuer`：验收数据，与正式目录分离。

运行依赖：Python 3.9+、OpenSSL 3+（Ed25519）。没有增加云服务器或短信服务。密码通过子进程 stdin 传给 OpenSSL，不写入命令行、数据库或日志。签发工具不记录 HTTP 内容日志。

经营者启动：

```sh
python3 operator_tools/license_issuer.py --root '/Volumes/EXTERNAL_USB/映序开发/2026-11-01/runtime/license-operator' --port 8848
```

客户首次安装公钥（参数须使用实际客户工作目录及经营者导出的公钥文件）：

```sh
python3 scripts/configure-license.py --root '/path/to/customer-workspace' --public-keys '/path/to/public-keys.json'
CONTENT_AGENT_ROOT='/path/to/customer-workspace' python3 scripts/start-licensed-workbench.py --port 8765
```

`start-licensed-workbench.py` 强制 `CONTENT_AGENT_LICENSE_MODE=required`，运行原 app。直接运行原 `app.py` 默认保留 `legacy` 开发兼容模式，不作为收费客户端发行入口；界面会显示开发模式提示。已有预览启动器在发现公钥配置后启用 required 模式。

## 交付边界

这是现有系统中的真实本地功能与预览，不是已签名公证的 macOS 安装包。正式打包需内置经营者公钥、OpenSSL 运行依赖和强制授权启动入口；排除 `operator_tools`、测试代码及所有运行数据。不得将仓库整体当作客户安装包发送。

安装标识目前保存在本地授权状态中，尚未绑定 macOS Keychain。复制整个工作目录可能复制安装标识，因此不宣称防克隆或强 DRM。纯离线不能远程撤销、统计真实激活、严格限制同时设备或可靠抵御系统时钟回拨。换机补发不会让旧机授权立即失效。

引导确认当前工作目录，不在运行中搬迁工作区；换外置硬盘需停止服务、迁移完整目录并修改启动路径。依赖检测与原项目一致，不代表所有第三方服务均配置成功。

加密私钥恢复已用隔离目录验证；客户备份不包含私钥。丢失正式私钥和备份后，需要新建密钥并给客户端更新公钥。正式私钥密码由经营者本人输入和保管。

签名调用依据：[OpenSSL pkeyutl 官方说明](https://docs.openssl.org/3.3/man1/openssl-pkeyutl/)，使用 Ed25519 原始载荷签名与验签，没有自制密码算法。
