# 本地 CLI 与 Agent 配置

入口：设置 → Agent 配置 → 选择 Agent → 执行引擎 → 保存。

文本能力支持 `codex_cli` 和 `kimi_cli`，每个 Agent 独立保存。新配置默认 Codex；已有合法 Kimi 配置保留。客户端在任务执行时读取对应 Agent 配置，不在失败后自动切换供应商。

已接入选择的能力：行业/抖音/小红书选题推荐、账号分析推荐、脚本文案、素材规划、文章生成、视频风险预审。采集浏览器、Remotion 渲染、FFmpeg 和本地配音仍使用各自原有引擎。

## 用户需要准备

在使用该客户端的电脑上安装并登录所选 CLI。登录状态与额度来自用户自己的 CLI；本功能无需在工作台另填文本模型 API Key。未安装、未登录或额度不足时给出错误，不改用另一个账户。

CLI 当前使用自身默认模型；配置里的模型文字不代表已经验证或固定了具体模型版本。图片与视频生成服务需要各自支持的生成接口，不能将文本 CLI 选择解释成自动支持这些接口。

## 验证边界

配置独立保存、切换读回、Kimi 调用路由、不静默回退已有自动化测试。此前已完成 Codex 通用提示真实调用；Kimi 路由通过模拟调用测试，不能据此宣称客户电脑上的 Kimi 登录与额度已经通过真实验证。
