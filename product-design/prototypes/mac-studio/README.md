# 映序 Mac 视觉与交互原型

本地预览，不部署生产，不连接账号或模型。视觉方向：Mac 的银灰窗口层次与克制蓝色，专业创作工具的分镜、画面、属性、轨道组织。

功能：项目列表/搜索、新建本机草稿、项目简报、文案自动保存、制作台分镜切换、CSS 动效演示、配乐音量与节奏方案、草稿 JSON 导出、运营看板阶段调整、模板与设置说明、深浅色切换。

边界：示例项目与固定分镜；未实现真实视频、音频、授权、生成、采集、磁盘管理、发布或平台数据。看板为手动示例状态，不代表后台任务状态。新建项目不会自动生成内容；制作台明确回到首个示范项目。

使用：任意本机静态服务器服务本目录，或通过映序本地预览中的 /mac-studio/ 打开。无外部依赖或网络资源。草稿存当前浏览器 localStorage；正式版本使用本地服务与数据库。不要在此输入真实密钥。

帮助页“首次激活”链接仅适用于本次配套预览部署；集成到正式应用时改为内部帮助与授权页面。
