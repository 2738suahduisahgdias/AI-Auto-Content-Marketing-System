# 完整后台改造预览

这是原仓库 React 前端内的 `/demo/` 交互预览，用来评审逐页改造计划；不是另一套正式业务系统，也没有接通原业务 API。普通路由继续进入原 AppProvider / App，演示路由不初始化真实 API 请求。

## 运行

在 `webapp` 内执行 `npm ci` 后运行 `npm run dev -- --port 8847`，访问 `http://127.0.0.1:8847/demo/`。依赖、代码和构建均保存在外接硬盘的开发分支。此处没有线上部署。

## 范围

17 个导航入口，原业务页逐项标明继承关系。项目使用简报、文案、视频制作、成片版本、发布与复盘五个页签。项目视图和运营看板共用演示记录。新增项目、编辑文案、文章转视频、模板应用、镜头修改、可选字幕、排期草稿和非敏感设置可以交互。

旁白／配乐按项目关联；真实浏览器媒体解码后读取时长，上传实拍按实际时长更新当前镜头。文件仅保留本次会话的对象 URL，不把媒体存进 localStorage。刷新后须重新选择，正式版将替换为本地数据库与文件定位服务。

演示草稿使用唯一键 `yingxu:preview-only:v1`，与正式数据隔离。这是原型临时存储，不是正式版的持久化架构。API 密钥输入禁用，不接受真实密钥。

## 外部依赖注释

文案、渲染、视频模型、配音字幕、音乐分析、平台浏览、发布、社媒查询、本地存储与授权均有页面注释，注明安装／配置、联网与数据、未配置替代路径和配置入口。设置中的“环境与依赖”统一汇总必需与按需项。

## 真实能力边界

模型生成、Remotion 成片、音乐分析、平台登录搜索下载发布、磁盘管理和离线签名未连接。对应按钮展示依赖与下一步，不生成假成功。模板示意为 CSS 布局／动效，不是 Remotion 样片；正式样片仍需后续制作。没有向任何平台发数据。

## 参数化设计规范试用（2026-11-01）

右上角可切换冷灰靛紫（Zinc）、暖白翡翠（Bone）和原 Mac 银灰。样式在 `premium.css` 隔离覆盖，使用设计变量复用现有 React 组件；未为试用重写业务组件或引入新 CSS 框架。主题保存在独立键 `yingxu:preview-design`，不替换项目草稿。

采用用户提供的画布／表面色、4px 间距节奏、12／16px 圆角、微阴影和缓出动效；首页使用 12 栏主次布局，制作台继续保留分镜、预览和属性。暖白主按钮将绿调深为 #087F5B，以提高白字可读性；字体优先用已安装系统字体，不增加在线字体请求。尊重减少动态效果设置。

本轮类型检查、独立构建和 6 项 demo 测试通过；浏览器检查冷灰首页、暖白项目页与切换。

预览不可达时，在仓库运行 `python3 scripts/start-yingxu-preview.py`。启动器检查 8847 端口，使用独立会话仅监听 127.0.0.1，日志在忽略的 reports 目录。它不注册开机启动；重启电脑或外接盘离线后需重新运行。

### 暖白琥珀金试用

按用户反馈将原 Bone 绿色方案更新为暖白底、琥珀橙行动色（#B85B0B）与少量香槟金（#B59A60）。保留 bone 存储值以兼容原偏好；品牌标识、模板编号和配乐轨用金色细节，制作画面保持中性。首次试用默认此方案，仍可切回冷灰与原版。
